## Условие задачи

Вычислить значение функции:

**F(x, y) = (sin^3(x) + ln(2y + 3x)) / (t^e + √x)**

при значении константы **t = 0.5**.


## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать константу:
   - `t` = 0.5.
3. Ввести исходные данные:
   - `x` — первый аргумент функции;
   - `y` — второй аргумент функции.
4. Проверить область определения функции:
   - если `x < 0` (корень из отрицательного числа) или `2 * y + 3 * x <= 0` (логарифм от неположительного числа), вывести сообщение «Значение функции не определено» и перейти к шагу 8.
5. Вычислить числитель:
   - `chislitel` = sin(`x`)^3 + ln(`2 * y + 3 * x`)
6. Вычислить знаменатель:
   - `znamenatel` = `t`^e + √`x`
7. Вычислить `F` = `chislitel` / `znamenatel` и вывести результат.
8. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_DEPRECATE
#define _USE_MATH_DEFINES
#include <stdio.h>
#include <math.h>
#include <locale.h>

int main()
{
	setlocale(LC_ALL, "RUSSIAN");

	double x, y;
	double t = 0.5;

	printf("\nВведите х\n");
	scanf("%lf", &x);
	printf("\nВведите y\n");
	scanf("%lf", &y);

	if (x < 0 || 2 * y + 3 * x <= 0)
	{
		printf("\n Значение функции не определено\n");
		return 0;
	}

	double chislitel = pow(sin(x), 3) + log(2 * y + 3 * x);
	double znamenatel = pow(t, exp(1)) + sqrt(x);


	double f = chislitel / znamenatel;

	printf("\nF = %lf\n", f);
	return 0;
}
```
